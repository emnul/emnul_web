# Issue Tracker

Issues for this repo live in **Linear**, managed via the Linear MCP tools available in this Claude Code session.

## How agents interact with issues

- **Create issues**: use the `save_issue` Linear MCP tool
- **Update issues**: use `save_issue` with the existing issue ID
- **List issues**: use `list_issues`
- **Read an issue**: use `get_issue`
- **Add comments**: use `save_comment`

## PRs as a request surface

`accept-prs: false` — External pull requests are not part of the triage queue.
